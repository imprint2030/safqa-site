# صفقة — سوق يمني للإعلانات المبوبة

موقع إعلانات مبوبة كامل (خادم + قاعدة بيانات + تسجيل دخول حقيقي)، مبني بـ **Node.js فقط بدون أي حزم خارجية** —
لا يحتاج `npm install`. هذا مقصود: الاستضافات المختلفة وبيئات التشغيل تختلف في إتاحة الوصول لسجل npm، وبإزالة
الاعتماد على الحزم الخارجية يضمن الموقع أنه يعمل مباشرة في أي مكان يتوفر فيه Node.js حديث.

## المتطلبات

- Node.js **22.5.0 أو أحدث** (لأن قاعدة البيانات تستخدم وحدة `node:sqlite` المدمجة في Node)

تأكد من إصدارك:
```bash
node -v
```

## التشغيل محليًا

```bash
node --experimental-sqlite server.js
```

ثم افتح المتصفح على:
```
http://localhost:3000
```

(المنفذ قابل للتغيير عبر متغير البيئة `PORT`، مثال: `PORT=8080 node --experimental-sqlite server.js`)

عند أول تشغيل يتم إنشاء قاعدة بيانات SQLite تلقائيًا في `data/safqa.db` مع بيانات تجريبية:
8 تصنيفات، مدن يمنية، 11 إعلانًا تجريبيًا، ومستخدم تجريبي واحد للتجربة:

- **البريد الإلكتروني:** demo@safqa.ye
- **رقم الجوال:** 777123456
- **كلمة المرور:** demo1234

## ما يعمل فعليًا في هذا الإصدار

- تصفح الرئيسية، التصنيفات (مع فلترة حسب المدينة)، وصفحة تفاصيل الإعلان
- تسجيل حساب جديد بالجوال أو البريد الإلكتروني، مع تشفير كلمة المرور (scrypt)
- تسجيل الدخول والخروج بجلسات حقيقية (Session) عبر كوكيز HttpOnly
- إضافة إعلان جديد (محمي بتسجيل الدخول) مع رفع حتى 3 صور فعليًا تُحفظ على الخادم
- لوحة تحكم لكل مستخدم: عرض إعلاناته، عدد المشاهدات، وحذف الإعلان (مع حذف صوره من القرص)
- حماية: لا يمكن لمستخدم حذف إعلان مستخدم آخر، ولا الدخول للوحة التحكم أو صفحة الإضافة بدون تسجيل دخول

## هيكل المشروع

```
safqa-site/
  server.js          نقطة الدخول + كل المسارات (routes)
  db.js              الاتصال بقاعدة البيانات + المخطط + البيانات التجريبية
  auth.js            الجلسات وتشفير/التحقق من كلمات المرور
  utils.js           دوال مساعدة (الوقت النسبي، تحليل النماذج)
  views/
    layout.js        الهيكل العام للصفحة + الهيدر والفوتر
    pages.js          كل صفحات الموقع (الرئيسية، التصنيف، الإعلان، الدخول، ...)
    icons.js          أيقونات SVG بسيطة
  public/
    css/style.css     التصميم الكامل (نفس ألوان وهوية النموذج: البني الطيني، أبيض النورة، أزرق القمريات، الأحمر المرجاني)
    uploads/          صور الإعلانات المرفوعة (تُنشأ تلقائيًا)
  data/               قاعدة بيانات SQLite (تُنشأ تلقائيًا عند أول تشغيل)
```

## الخطوات التالية قبل النشر الفعلي في اليمن

هذا إصدار جاهز للتجربة والتطوير، لكن قبل إطلاقه لمستخدمين حقيقيين ينصح بـ:

1. **استضافة حقيقية**: رفعه على خادم (VPS) أو منصة استضافة تدعم Node.js 22+، وربطه بنطاق (دومين) خاص بك
2. **رمز تحقق فعلي (OTP)**: التسجيل برقم الجوال حاليًا لا يرسل رمز تحقق حقيقي (يحتاج ربط مع مزوّد رسائل SMS يمني أو دولي)
3. **متغيرات بيئة للأسرار**: نقل أي مفاتيح لاحقة (مزود SMS، بوابة دفع) إلى ملف `.env` بدل كتابتها في الكود
4. **نسخ احتياطي دوري** لقاعدة البيانات `data/safqa.db`
5. **حد أقصى لحجم الصور** أعلى من 1 ميجابايت الحالي إذا احتجت جودة أعلى (يتطلب ضغط الصور بدل base64 المباشر)
6. **نظام رسائل بين البائع والمشتري** ونظام مفضلة — غير مفعّلين بعد في هذا الإصدار
